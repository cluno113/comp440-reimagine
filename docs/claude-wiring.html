What is not lit up, and how to turn it on

  1. parked Skills, permissions and both hooks live in .claude.old/. Commit 569a7ae, Turn off the tutor rules, renamed it. Renaming it back to .claude/ loads them in the next session.
  2. parked guard.py only runs through the PreToolUse hook. Until that loads, nothing enforces the run gate. Only the written rule in CLAUDE.md holds it.
  3. working CLAUDE.md is active because the parent folder comp440-reimagine/ holds an identical copy. Inside this repo it is CLAUDE.md.old.
  4. not used No MCP server is part of this activity. Claude reaches everything through the built-in Bash, Read, Edit and Skill tools.
  5. not yet results/ and the 14 XXXX slots fill in as a student works through Parts 0–5.
